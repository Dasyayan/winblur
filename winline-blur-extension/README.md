# 🛡️ Winblur v4 — Блюр Winline на slay-award.ru

Chrome-расширение для точечного размытия только рекламных блоков Winline.

---

## ✅ Что делается

| Тип | Действие | Что попадает |
|-----|----------|--------------|
| **Блюр** (картинки/видео) | Размывает изображение с силой 8px | Логотипы WINLINE, hero-баннер, промо-картинки в легендах и золотом билете |
| **Замена текста** | `WINLINE` → `5opka42` | Все текстовые надписи с упоминанием бренда |

---

## ❌ Что НЕ трогаем

- Кнопка **«Авторизоваться»** — работает как прежде
- Кнопка **«Купить билет»** — кликабельна
- Текст **«SLAY»** — остаётся читаемым
- Навигация, номинации, FAQ, таймер — без изменений

---

## 🔧 Установка

1. `chrome://extensions/` → **«Режим разработчика»** (вкл.)
2. **«Загрузить распакованное расширение»** → `D:\nrc\poo\winline-blur-extension`
3. Откройте [slay-award.ru](https://slay-award.ru/) — готово

После редактирования файлов нажмите **🔄 Обновить** на странице расширений.

---

## ⚙️ Панель управления

Правый нижний угол:
- **Счётчик** `N / 20` — фиксированный лимит
- **Размытие** — ползунок 2–20px (по умолчанию 8)
- **Выключить / Включить** — полная остановка
- **Обновить** — перезапуск сканирования + замена текста

---

## 🚀 Как работает замена текста

Используется `TreeWalker` по всем текстовым узлам страницы:

```javascript
textNode.textContent = original
  .replace(/winline/gi, '5opka42')
  .replace(/винлайн/gi, '5opka42');
```

Это меняет **только текст**, не трогая HTML-структуру, классы и атрибуты.

---

## 🔧 Настройки

Откройте `content.js`, блок `const C`:

```javascript
const C = {
  blurAmount : 8,    // px — сила размытия изображений
  maxBlocks  : 20,   // макс. элементов (фиксирует счётчик)
  textReplace: '5opka42', // замена для WINLINE
};
```

Перезагрузите расширение после изменений.
