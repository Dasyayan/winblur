🛡️ Winline Blur Extension

Chrome расширение для автоматического блюра рекламы и надписей Winline на сайте slay-award.ru

Как установить расширение

  1. Откройте Chrome и перейдите по адресу:
    chrome://extensions/
  2. Включите режим разработчика — переключатель в правом верхнем углу
  3. Нажмите «Загрузить распакованное расширение»
    Выберите папку: D:\nrc\poo\winline-blur-extension
  4. Готово! Расширение активировано. Откройте slay-award.ru

Что делает расширение

  • Автоматически обнаруживает и блюрит все элементы с текстом «Winline» / «винлайн»
  • Скрывает iframe-рекламу с доменов winline
  • Работает с динамически загружаемым контентом (MutationObserver)
  • Показывает плавающую панель управления с настройками

Плавающая панель

В правом нижнем углу страницы появится панель, где можно:

  • Изменить интенсивность блюра (ползунок)
  • Включить/выключить расширение
  • Перезапустить сканирование

Регулировка блюра

Если стандартная интенсивность не подходит, откройте content.js и измените:

blurAmount: 8  // ← значение в пикселях (от 2 до 20)

Файлы расширения

winline-blur-extension/
├── manifest.json      ← конфигурация расширения (Manifest V3)
├── content.js         ← основной скрипт (детекция + блюр)
├── styles.css         ← стили блюра и панели
├── build-icons.mjs    ← генератор иконок
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png

Обновление после изменений

После редактирования файлов на chrome://extensions/ нажмите кнопку 🔄 (обновить) у расширении.
